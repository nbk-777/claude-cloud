# გვერდი „3D Balcony Installation“

**მისამართი:** ჩანართი **„3D აივნის ინსტალაცია“**, ან `#balcony-3d`, მაგ.
`https://nbk-777.github.io/claude-cloud/#balcony-3d`.

ეს ინტერაქტიული WebGL სცენაა (Three.js 0.186.1). ყველა მოწყობილობა კოდითაა შექმნილი; გარე მოდელები ან სერვერები არ გამოიყენება.
სცენა აჩვენებს **არსებული** სიმულაციის მდგომარეობას — საკუთარ სიმულაციას არ აწარმოებს.

> საილუსტრაციო პროტოტიპია. ის არ ცვლის ქვაბის მართვას, დამცავ მოწყობილობებს, ყინვისგან დაცვას, მინიმალური ნაკადის
> და ტუმბოს დაყოვნების მოთხოვნებს, ჰიდრავლიკურ პროექტს ან პროფესიონალურ გაშვებას. მონტაჟის ინსტრუქცია აქ არ არის და
> არ ამტკიცებს, რომ ქვაბის აივანზე დაყენება დაშვებულია.

## სცენაში
- **აივანი:** კედელი, კარი, ფილის იატაკი, მოაჯირი, დღის სინათლე და ჩრდილები.
- **ქვაბი:** ზოგადი კედლის კომბი ქვაბი (საილუსტრაციო, ბრენდის გარეშე). დაგეგმილია Ariston Genus ONE 24, მაგრამ ზუსტი ვარიანტი დაუდასტურებელია.
  - ცეცხლი ჩანს **მხოლოდ მაშინ, როცა სიმულაციაში სანთურა ანთია**.
  - ტუმბოს ინდიკატორი ბრუნავს, როცა ტუმბო მუშაობს.
  - დისპლეი აჩვენებს t°-ს, რეჟიმს და მოთხოვნას.
- **კოლექტორი:** **პირდაპირ ქვაბის ქვეშ**.
  - მიწოდების ბარზე 14 აქტუატორია; დაბრუნების ბარზე — 14 ნაკადმზომი.
  - ქვემოთ 14 წყვილი მილია, ოთახის ფერის ნიშნებით.
- **ზონის კონტროლერი (იხსნება):** ღილაკი **„კონტროლერის გახსნა“** (ან ინსპექტორიდან) ხსნის გამჭვირვალე სახურავს და კამერა შიგნით შედის. დაფაზე ქართული წარწერებია:
  - **ზონები:** Z1–Z8 შესასვლელები (L / N / S); Z1–Z4 გამოყენებულია, Z5–Z8 — თავისუფალი. თითოეულ ზონას აქვს LED და აქტუატორების გამოსავალი (A~ / A~).
  - **სხვა ნაწილები:** კვება L / N / PE, ფუზი 15A, რელე NO / COM / NC, DIP 0 / 2 / 5 წთ, ტუმბო L1 / N1.
  - **სიმულაცია:** LED-ები და სადენები ნათდება სიმულაციის მიხედვით. ყველა კლემა და სადენი დაწკაპუნებადია და ინსპექტორში ჩანს მისი ფუნქცია.
- **თერმოსტატების შეერთება:** თითოეული თერმოსტატიდან 3-ძარღვიანი კაბელი (ყავისფერი L, ლურჯი N, მწვანე სიგნალი) საკაბელო არხით მიდის კონტროლერის ზედა სალნიკამდე, შიგნით — თავისი ზონის L / N / S კლემებზე.
  - თერმოსტატები დალაგებულია Z1–Z4 რიგით, ამიტომ კაბელები არ იკვეთება.
- **აქტუატორების შეერთება:** თითოეულ აქტუატორს თავისი კაბელი აქვს ქვედა არხით ზონის A~ კლემებამდე (პარალელურად).
- **რელე → ქვაბი:** ორი ნარინჯისფერი ძარღვი, მშრალი კონტაქტი; ქვაბის კლემაზე 230V არასოდეს.
- **ზოგადი მოდელი:** კლემების წარწერები მოდელზეა დამოკიდებული; რეალური შეერთება — კვალიფიციური ელექტრიკოსი.
- **4 თერმოსტატი:** Living Room, Bathroom, Child's Bedroom, Main Bedroom. **საილუსტრაციოდ ერთად არიან ნაჩვენები**; რეალურად თითოეული თავის ოთახშია.
- **მხოლოდ კონტექსტი:** გაზი, საკვამური, დამცავი სარქვლის გამონადენი, ქსელის კვება — „საჭიროა პროფესიონალური მონტაჟი“. მათი შეერთება შეუძლებელია.

## მართვა
- **ფუნქციური 3D ღილაკები:** სცენაში თითოეულ თერმოსტატზე ⏻ / − / + და ქვაბის პანელზე − / + (მიწოდების სასურველი t°) — იგივე მართვაა, რაც გვერდით პანელზე; დაჭერისას ჩნდება შეტყობინება. ტელეფონზე თერმოსტატზე დაჭერა მასზე აახლოებს კამერას, რომ ღილაკები დიდი იყოს.
- **ენა:** ყველა წარწერა და აღწერა ქართულადაა.
- **ნავიგაცია:** ბრუნვა, მასშტაბირება, გადაადგილება. კამერები: მთელი აივანი, ქვაბი, კოლექტორი, კონტროლერი, თერმოსტატები, „კამერის აღდგენა“.
- **ინსპექტორი:** დააწკაპუნეთ ნებისმიერ კომპონენტზე. ინსპექტორი აჩვენებს ფუნქციას და მიმდინარე სიმულირებულ მდგომარეობას; არჩეული ობიექტი მონიშნულია.
- **თერმოსტატის არჩევა:** ინათება მისი ზონის აქტუატორები და კონტურები.
- **„Explain system“:** აჩვენებს მიწოდების (წითელი), დაბრუნების (ლურჯი), სიგნალის (მწვანე) და ქვაბის მოთხოვნის (ნარინჯისფერი) გზებს.
- **თერმოსტატები ამ გვერდიდანაც იმართება:** სასურველი t° ±0.5 და ჩართვა/გამორთვა.

## კომპონენტების შეერთება (კონცეპტუალური)
- **შეერთებები:**
  - ქვაბის მიწოდება → კოლექტორის მიწოდება
  - კოლექტორის დაბრუნება → ქვაბის დაბრუნება
  - თერმოსტატი → თავისი ზონა
  - ზონის გამოსავალი → აქტუატორების ჯგუფი
  - კონტროლერის მოთხოვნა → ქვაბი
- **ვალიდაცია:**
  - შეუთავსებელი პორტები არ ერთდება.
  - მიწოდება და დაბრუნება ერთმანეთს არ უერთდება.
  - ზონის პორტები მხოლოდ თავის ზონას უერთდება.
  - ერთი პორტი — ერთი კავშირი.
- **ეფექტი** (მხოლოდ ამ გვერდზე, როცა რეჟიმი ჩართულია):
  - გათიშული თერმოსტატი → მოთხოვნა არ არის.
  - გამოსავლის კავშირი არ არის → აქტუატორები დახურულია.
  - მოთხოვნის კავშირი არ არის → ქვაბი არ ირთვება.
  - წყლის გზა არასრულია → ნაკადი არ ჩანს.
- **ღილაკები:** „Load assembled example“ და „Reset connections“.
