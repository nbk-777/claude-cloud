# სისტემის არქიტექტურა (როგორც მოდელირებულია)

## ჰიდრავლიკა
```
Ariston Genus ONE 24 (შიდა ტუმბო + 8 ლ ავზი + 3 ბარი დამცავი + სამსვლიანი + ავტ. ბაიპასი)
  A (მიწოდება, წითელი) ──► მიწოდების კოლექტორი ─► [სარქველი + 230V NC აქტუატორი] ×14 ─► კონტურები L01…L14
                         ◄── დაბრუნების კოლექტორი (თავსახურები, ნაკადმზომები) ◄──
  E (დაბრუნება, ლურჯი) ◄──┘
  D (ცივი, ფირუზისფერი) ──► ნაკადის სენსორი ─► ფირფიტოვანი თბომცვლელი ─► B (ცხელი, ნარინჯისფერი) ──► შხაპი
  C გაზი, F დამცავის გამონადენი, H დრენაჟი, I კონდენსატი — მხოლოდ კონტექსტი
```
- ძირითად სცენაში არ არის გარე ტუმბო, შერევის სარქველი, ჰიდრავლიკური გამყოფი ან ბუფერი. ისინი ჩანს მხოლოდ არჩევით ფენაში: „შეიძლება საჭირო იყოს პროექტის მიხედვით“.
- ნაგულისხმევად იატაკისთვის გამოიყენება ქვაბის დაბალი დიაპაზონი (20–45 °C).

## მართვა
```
Beok თერმოსტატი (ოთახში)  ─3 ძარღვი: L (ყავისფ.), N (ლურჯი), სიგნალი (მწვანე)─►  ცენტრის ზონა Zn (8-დან 1..4)
Zn აქტუატორის წყვილი (A~ L / A~ N, 230V) ─► ოთახის ყველა აქტუატორი პარალელურად (+ ჰოლი / გარდერობი მფლობელ ზონაზე)
რომელიმე ზონა ჩართულია ≥ DIP დაყოვნება (0/2/5 წთ) ─► რელე COM–NO იკეტება ─► Ariston TA1 (მშრალი კონტაქტი, 12V DC)
ტუმბოს გამოსავალი L1/N1 — არ გამოიყენება (ქვაბის ტუმბო)
FLOOR/TA2 — არჩევითი იატაკის დამცავი თერმოსტატი (პარამ. 223 = 0)
```
- ზონები: Z1 მისაღები, Z2 საბავშვო, Z3 მთავარი საძინებელი, Z4 სააბაზანო.
- მიუნიჭებელ კონტურს აქტუატორის სადენი არ აქვს, ამიტომ მისი NC სარქველი დახურული რჩება.
- ნაკადს არაფერი ადასტურებს: აქტუატორი პოზიციას არ აბრუნებს, რელე კი ტაიმერით იკეტება.
- ზუსტი სქემა (კლემა-კლემა, ზოგადი მოდელი): ჩანართი **„მოწყობილობები და მონტაჟი“ → „მართვის სქემა“**.

## პროგრამა
```
src/model   ტიპიზებული კონფიგურაცია, გეგმის გეომეტრია, კონტურების განლაგება, ვალიდაცია, შენახვა (localStorage v1, JSON)
src/sim     დეტერმინისტული ძრავა (step/runFor/Clock), ბრძანების ჯაჭვი, სცენარები
src/ui      React + SVG ხედები; useSimulation ძრავას requestAnimationFrame-ით ამუშავებს
src/data    წყაროები, ფაქტები, აღჭურვილობა, შემოწმების სია, ინსპექტორის ტექსტები, ღია საკითხები
src/i18n    ქართული ტექსტები
```
- აწყობა ქმნის ერთ `dist/index.html` ფაილს (vite-plugin-singlefile), რომელიც დისკიდან ქსელის გარეშე იხსნება.
- GitHub Pages: `.github/workflows/pages.yml`.
