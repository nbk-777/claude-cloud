# იატაკქვეშა გათბობის ციფრული მოდელი — ინტერაქტიული პროტოტიპი

ერთი კონკრეტული ბინის ინტერაქტიული მოდელი. ბინა ≈74.3 მ²-ია, აქვს 14 იატაკის კონტური, 4 ოთახის
თერმოსტატი (მისაღები, საბავშვო, მთავარი საძინებელი, სააბაზანო), Ariston Genus ONE 24 კომბი ქვაბი
მარცხენა აივანზე და 8-ზონიანი გაყვანილობის ცენტრი.

თითოეულ ოთახში რთავთ/თიშავთ გათბობას და ცვლით სასურველ ტემპერატურას. შემდეგ ხედავთ მთელ ჯაჭვს:

თერმოსტატის სიგნალი → ცენტრის ზონა → 230V NC აქტუატორები თბება და იღება → DIP დაყოვნება → რელე COM–NO კეტავს TA1-ს →
ქვაბის ტუმბო და სანთურა ირთვება → ცხელი წყალი მხოლოდ ღია კონტურებში → იატაკი თბება → ჰაერი თბება →
მიზანი მიღწეულია → აქტუატორები იხურება → რელე იხსნება → სანთურა ჩერდება → ტუმბო დაყოვნებით → იატაკში ნარჩენი სითბო.

> **ეს პროტოტიპია და არა საპროექტო ინსტრუმენტი.** ყველა თბური რიცხვი (დანაკარგები, ტევადობები, ნაკადები, kW,
> გათბობის დრო) დემო-დაშვებაა. ეს არ არის თბოდანაკარგის გაანგარიშება, ქვაბის/ტუმბოს შერჩევა, უსაფრთხო პარამეტრები
> ან მონტაჟის ინსტრუქცია. იხ. [ASSUMPTIONS.md](ASSUMPTIONS.md).

**ონლაინ:** https://nbk-777.github.io/claude-cloud/

## გაშვება

```bash
npm install
```

```bash
npm run dev          # http://localhost:5173
```

```bash
npm run build        # → dist/index.html (ერთი ფაილი; იხსნება პირდაპირ დისკიდან)
```

```bash
npm test             # Vitest + React Testing Library
```

```bash
npm run build && npm run smoke   # ბრაუზერის ტესტი + სკრინშოტები e2e/screenshots/-ში
```

## ფერების კოდი
- წითელი = გათბობის მიწოდება (A)
- ლურჯი = გათბობის დაბრუნება (E)
- ნარინჯისფერი = ცხელი სამომხმარებლო წყალი (B)
- ფირუზისფერი = ცივი წყალი (D)
- ყვითელი = გაზი (C, მხოლოდ კონტექსტი)
- ნაცრისფერი = კონდენსატი (I)
