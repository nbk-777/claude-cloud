# სიმულაციის მოდელი

ძრავა არის `src/sim/engine.ts`. პარამეტრები `src/sim/params.ts`-შია: `BOILER` — ინსტრუქციიდან, `DEMO` — **მხოლოდ დემო-დაშვებები**.

- **დრო:** ფიქსირებული ბიჯი 1 წმ, სიჩქარე 1×–60×.
- **Clock:** რეალურ დროს × სიჩქარეს მთელ ბიჯებად გარდაქმნის, ამიტომ შედეგი კადრების სიხშირეზე არ არის დამოკიდებული.
- **დეტერმინიზმი:** `step(state, cfg)` სუფთა ფუნქციაა.
- **პაუზა/გადატვირთვა:** პაუზა აჩერებს ბიჯებს; გადატვირთვა თავიდან ქმნის საწყის მდგომარეობას ან მიმდინარე სცენარს.

## ბიჯის თანმიმდევრობა
1. **თერმოსტატები.** ჰისტერეზისი ±h/2 (h = 0.4 K), მინ. ჩართვა/გამორთვა 120 წმ. გამორთული ან სენსორდაკარგული თერმოსტატი არ ითხოვს.
2. **გაყვანილობის ცენტრი.** ზონის გამოსავალი = თერმოსტატის მოთხოვნა. რელე (TA1) იკეტება, თუ რომელიმე ზონა ჩართულია ≥ `relayDelayS` (DIP: 0, 120 ან 300 წმ).
3. **აქტუატორები** (NC). ბრძანების შეცვლის შემდეგ თბური დაყოვნება (`actuatorDelayS`), შემდეგ წრფივი სვლა (`actuatorTravelS`). „გაჭედილი“ აქტუატორი რჩება 0-ზე და აჩვენებს `fault`-ს.
4. **ქვაბი:** მოლოდინი / გათბობა / ცსწ / დაყოვნება / ხარვეზი.
   - **იატაკის დამცავი (არჩ.):** მიწოდების t° > ზღვარი → ხარვეზი `116`. სანთურა ჩერდება, ცსწ არ არის, ტუმბო 3 წთ. აღდგება ზღვარზე 5 K-ით დაბლა.
   - **ცსწ:** შხაპის ნაკადი ≥ 2 ლ/წთ → სამსვლიანი ცსწ-ზე, სანთურა ირთვება, იატაკი არ იკვებება. ნაკადის ზღვარი `384/ΔT` ლ/წთ; მის ზემოთ გამოსავალი t° = ცივი + 384/ნაკადი. სიმძლავრე 2.4–24.9 kW.
   - **გათბობა** (TA1 დაკეტილი): ტუმბო მუშაობს.
     - ღია კონტური თუ არ არის → **dead-head** გაფრთხილება, სანთურა არ ირთვება.
     - სანთურა ირთვება, როცა t° < სასურველი − 3 K; ითიშება, როცა t° > სასურველი + 3 K; ამის შემდეგ **ანტი-ციკლი** 180 წმ (პარამ. 236).
     - მოდულაცია [2.6, 23.6] kW-ში (50/30).
   - **დაყოვნება:** TA1 გახსნის შემდეგ ტუმბო 180 წმ (პარამ. 237), შემდეგ მოლოდინი.
   - **ნიშნები:** `lowLoad` (< 2.6 kW) და `shortCycling` (≥ 4 ჩართვა საათში).
5. **კონტურები:** ნაკადი არის, თუ ტუმბო მუშაობს, სამსვლიანი CH-ზეა, კონტური ოთახზეა მინიჭებული და პოზიცია > 0.02.
   - კონტურის ფართი = ოთახის ფართი / კონტურების რაოდენობა. `UA = 10 W/მ²K × ფართი`.
   - ნაკადი = 1.6 ლ/წთ × პოზიცია (საილუსტრაციო).
   - სითბო იატაკში: `Q = UA(T_მიწ − T_იატ)/(1 + UA/(2ṁc))`.
6. **ოთახები:** ორი კვანძი.
   - იატაკი: 80 kJ/მ²K; ჰაერი: 30 kJ/მ²K.
   - იატაკი→ჰაერი: 10 W/მ²K.
   - დანაკარგი გარეთ: 1.4 W/მ²K.
   - ოთახებს შორის სითბოს გაცვლა არ არის მოდელირებული.
7. **ისტორია:** ყოველ 30 წმ-ში; ინახება ბოლო 6 სთ.

## განზრახ არ არის მოდელირებული
- წვა, გაზის ხარჯი, საკვამური.
- წნევა, ტუმბოს მრუდი, წნევის ვარდნა, ბალანსირება, კონტურის სიგრძე — **ტუმბოს ადეკვატურობაზე დასკვნა არ კეთდება**.
- რეალური თბოდანაკარგი და გათბობის დრო.
- ელექტრო დატვირთვა და საწყისი დენი.
