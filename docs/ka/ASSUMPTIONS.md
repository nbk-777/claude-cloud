# ფაქტები, დაშვებები და ღია საკითხები

იგივე სიები აპლიკაციაშიცაა: ჩანართები **„წყაროები და დაშვებები“** და **„ღია საკითხები“**. ერთადერთი წყარო არის `src/data/reference.ts`.

## მომხმარებლის ფაქტები
**პირველი შეტყობინება:**
- მილები დაგებულია და იატაკი სრულად დაფარულია.
- კოლექტორის ადგილზე მოდის 14 წყვილი → 14 კონტური (საჭიროებს ადგილზე დადასტურებას).
- ფართები გეგმიდან: 32.04 მისაღები, 10.26 საბავშვო, 16.01 მთავარი საძინებელი, 5.48 სააბაზანო, 7.11 ჰოლი, 3.40 გარდერობი.
- თერმოსტატი ყველა საცხოვრებელ ოთახშია: მისაღები, ორივე საძინებელი, სააბაზანო (4 ცალი).
- ამ ოთახებიდან დაგებულია 3-ძარღვიანი კაბელები.
- ჰოლს და გარდერობს აქვს კონტური, თერმოსტატი — არა.
- ქვაბი Ariston Genus ONE 24 მარცხენა აივანზე, თერმო-კარადაში.
- კოლექტორი ნაყიდი არ არის და მისი ადგილი უცნობია.
- ცხელი წყალი სააბაზანოს შხაპამდე; ოთახების დამოუკიდებელი მართვა.

**მეორე შეტყობინება:**
- თერმოსტატები: Beok 220V Wi-Fi, 3A, Tuya — **ჯერ არ არის დამონტაჟებული**.
- აქტუატორები: 230V, NC, M30×1.5, ≈2–3 W, იღება ≈3–5 წთ-ში.
- ცენტრი: 8 ზონა (L / N / სიგნალი / აქტუატორის წყვილი), ფუზი 15A, რელე NO/COM/NC, DIP დაყოვნება, ტუმბო L1/N1, PE.
- კოლექტორი: აქტუატორები მიწოდებაზე, ხელის თავსახურები დაბრუნებაზე, ნაკადმზომები.
- TA1: ქარხნული ჯამპერი მოიხსნება, მხოლოდ მშრალი კონტაქტი, არასოდეს 230V.

**მესამე და შემდეგი შეტყობინებები:**
- დეტალური ილუსტრაციები; DIP 0 / 2 / 5 წთ.
- ცალკე გვერდი ქვაბით აივანზე და მოწყობილობებით.
- ზუსტი მართვის სქემა.
- მკაფიო ცხელი/ცივი წყლის ფერები.
- დოკუმენტაცია ქართულად.

## წინააღმდეგობები შეტყობინებებს შორის
- **ფართები.** გეგმა: 32.04 / 16.01 / 5.48 / 10.26 / 7.11. მეორე შეტყობინება: 30 / 21 / 10 / 9, ჰოლის გარეშე. **მოდელი იყენებს გეგმას.**
- **თერმოსტატები.** „არსებობს“ vs „ჯერ არ არის დამონტაჟებული“. მოდელი: დაგეგმილი Beok.
- **სააბაზანოს კონტურები.** 1 vs 2.
  - ნაგულისხმევი განაწილება: 6/3/2/1/1/1.
  - ალტერნატივა: 6/3/2/2/0/1 (ერთი ღილაკით).

## პროტოტიპის დაშვებები
- ოთახების სახელები (შეცვლადია).
- ჰოლის კონტური მიახლოებულია 3 მართკუთხედით (≈7.2 მ², გეგმაზე 7.11 მ²). საბავშვოს სიღრმე 3.80 მ = 10.26 / 2.70.
- ყველა მოწყობილობის ადგილი და მილების/კაბელების მარშრუტი (გეგმაზე არ ჩანს).
- „მოწყობილობები და მონტაჟი“ გვერდზე ტიპიური აქსესუარები:
  - ჩამკეტი ონკანები ქვაბის ქვეშ და კოლექტორზე
  - ჰაერის გამშვები და დრენაჟი
  - კედლის გასასვლელი
  - კოლექტორის კარადა
  - ორპოლუსა ჩამრთველი (ინსტრუქცია მოითხოვს ორპოლუს გამორთვას, GB გვ.11)
- კონტურის სერპანტინის ფორმა — ვიზუალური მოდელი.
- 3-ძარღვიანი კაბელი: 1 = L, 2 = N, 3 = სიგნალი (ზოგადი მოდელი).
- აქტუატორი: 90 წმ დაყოვნება + 150 წმ სვლა ≈ 4 წთ; დახურვაც იგივე.
- რელე იკეტება DIP დაყოვნების შემდეგ (ნაგულისხმევი 5 წთ). ბოლო-გადამრთველის უკუკავშირი არ არის.
- ცსწ-ს პრიორიტეტი სამსვლიანი სარქვლით — ტიპიური ქცევა, დასადასტურებელი.
- აპი/ღრუბელი ოფლაინ → ადგილობრივი მართვა გრძელდება (არქიტექტურის დაშვება).
- სენსორის დაკარგვა → მოთხოვნა ითიშება (მხოლოდ სიმულაციის პოლიტიკა).
- ნაკადის გზა არ არის → სიმულაცია სანთურას არ ანთებს. რეალური ქცევა უცნობია; ინსტრუქციაში შიდა ბაიპასია.
- ხარვეზი 116-ის დროს ტუმბოს დაყოვნება 3 წთ — დემო.
- დამცავი თერმოსტატი 55 °C / 5 K — დემო.
- ყველა მნიშვნელობა `DEMO`-ში (`src/sim/params.ts`).

## ღია საკითხები / პროფესიონალის შემოწმება
იხ. [INSTALLER-CHECKLIST.md](INSTALLER-CHECKLIST.md). მოკლედ:
- კონტური→ოთახი რუკა.
- კაბელის ძარღვები და თერმოსტატის კლემები.
- ცენტრის ზონის დენის ლიმიტი (მისაღების ზონა: 6 + ჰოლი + გარდერობი = 8 აქტუატორი, ≈16–24 W).
- რელეს მშრალი კონტაქტი TA1-მდე (12V DC, volt-free).
- DIP მნიშვნელობები.
- შერევის კვანძი, გარე ტუმბო, ბაიპასი; ტუმბოს ადეკვატურობა; სისტემის მოცულობა vs 8 ლ.
- თერმო-კარადა: ყინვა, კონდენსატი, ვენტილაცია, საკვამური (+5 °C მინ.).
- ქვაბის ზუსტი ვარიანტი.
- ელექტრო — ელექტრიკოსი; ქვაბი — Ariston-ის ტექნიკოსი.
